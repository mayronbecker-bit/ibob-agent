Pré-requisitos
Contas e acessos — antes de abrir o Claude Code
01
Criar conta no Supabase
Banco de dados central do agente. Gratuito para começar.
humanoconfigcrítico
  • Acesse supabase.com e crie uma conta gratuita
  • Crie um novo projeto — nome sugerido: ibob-agent
  • Salve a senha do banco que o Supabase vai gerar
  • Vá em Settings → API e anote: Project URL, anon key e service_role key
  • A service_role key vai apenas para o Railway — nunca para o código
Atenção: a service_role key dá acesso total ao banco. Guarde em local seguro.
02
Criar conta no Railway e repositório GitHub privado
Onde os scripts Python vão rodar. Deploy automático via GitHub.
humanoconfig
  • Crie um repositório privado no GitHub: ibob-agent
  • Adicione .env e *.env no .gitignore antes do primeiro commit
  • Acesse railway.app e crie conta com GitHub
  • Crie um novo projeto vazio — nome: ibob-agent
  • Não conecte o repositório ainda — isso acontece na Fase 2
Repositório deve ser privado. Nunca deixe tokens no histórico de commits.

Obter chave da Anthropic API
O Claude será o cérebro do Decision Engine.
humanoconfigcrítico

  • Crie uma chave — nome: ibob-agent-production
  • Copie a chave imediatamente — não fica visível depois

Esta chave vai apenas para as variáveis de ambiente do Railway. Nunca no código.

05
Solicitar Developer Token do Google Ads
Pode levar 1–3 dias. Solicite agora para não travar a Fase 2.
humanoconfigcrítico
  • Acesse ads.google.com → Ferramentas → Central da API
  • Solicite o Developer Token — escolha acesso padrão
  • Acesse console.cloud.google.com e crie um projeto: ibob-agent
  • Ative a Google Ads API no projeto
  • Vá em Credenciais → Criar → OAuth 2.0 Client ID (tipo: Desktop App)
  • Baixe o JSON de credenciais
  • Execute o fluxo OAuth uma vez para gerar o refresh token
Faça isso hoje. A aprovação do Developer Token é imprevisível e pode travar toda a Fase 2 se deixar para depois.
GOOGLE_ADS_DEVELOPER_TOKEN=xxxxx GOOGLE_ADS_CLIENT_ID=xxxxx.apps.googleusercontent.com GOOGLE_ADS_CLIENT_SECRET=xxxxx GOOGLE_ADS_REFRESH_TOKEN=xxxxx GOOGLE_ADS_CUSTOMER_ID=123-456-7890
06
Configurar Meta Marketing API
Token de longa duração com escopo mínimo ads_management.
humanoconfigcrítico
  • Acesse developers.facebook.com → Criar App → tipo Business
  • Adicione o produto Marketing API ao app
  • Gere token com permissões: ads_management e ads_read apenas
  • Converta para Long-Lived Token via endpoint /oauth/access_token
  • Token dura 60 dias — o agente renova automaticamente a cada 55
Não adicione permissões de pages, Instagram ou dados de usuário. Escopo mínimo protege a conta.
META_ACCESS_TOKEN=xxxxx META_AD_ACCOUNT_ID=act_123456789
07
Auditar e corrigir rastreamento (tracking)
Pré-requisito absoluto do Data Trust Layer. Não pule.
humanocríticoteste
  • Instale Tag Assistant (Chrome) e navegue pelo e-commerce — confirme evento purchase com value e items
  • Instale Meta Pixel Helper — confirme evento Purchase com valor
  • No Google Ads: Ferramentas → Conversões — confirme que há valor de conversão registrado
  • No GA4: Relatórios → Receita deve bater com o faturamento real (tolerância 10%)
  • Divergência encontrada? Corrija antes de avançar
Se o tracking estiver errado, o DTL vai ficar em VERMELHO o tempo todo e o agente não vai propor nada.
Critério de aprovação: divergência entre GA4 e plataformas < 15% por 3 dias.
08
Padronizar UTMs e nomenclatura de campanhas
Padrão que o agente vai usar para cruzar dados entre fontes.
humanocrítico
  • Renomeie campanhas: [plataforma]_[funil]_[produto]_[tipo]
  • Exemplo: google_ecommerce_motor_weg_search
  • Configure UTMs em todos os anúncios: utm_source, utm_medium, utm_campaign, utm_content
  • Para funil consultivo: adicione utm_term com o produto/solução
  • No CRM: crie campos obrigatórios utm_source e utm_campaign no cadastro de lead
09
Classificar produtos e conectar o Orbita
Separar físico vs encomenda e obter acesso ao endpoint de margem.
humanoconfig
  • Crie uma planilha: coluna SKU e coluna tipo (fisico / encomenda)
  • Físico → pausa automática se estoque < 5 unidades
  • Sob encomenda → nunca pausa, sempre ativo, vira lead para o comercial
  • Contate a equipe do Orbita: solicite acesso ao endpoint de margem líquida por SKU
  • Peça a documentação do endpoint — o Claude Code vai precisar do formato exato da resposta JSON
Confirme com o Orbita: a margem retornada já desconta frete, comissão de marketplace e impostos?

Crie o schema SQL completo para o Supabase do agente de tráfego pago da iBob. Tabelas necessárias: - proposals (id, action_type, campaign_id, proposed_change, impact_score, status, approved_by, approved_at, rationale, outcome_d7, prompt_version, threshold_version, created_at) - decision_memory (id, proposal_id, action_type, result, approved, rejection_reason, causal_effect, confidence) - execution_log (id, proposal_id, executed_at, api_service, api_endpoint, api_request, api_response, previous_state, rollback_available, approved_by, prompt_version) - agent_versions (id, version_id, version_type, component, previous_value, new_value, proposed_by, approved_by, approved_at, active_since, rationale, rollback_to, status) - agent_state (dtl_blocked, dtl_reason, dtl_state, last_collection, orbita_last_pull, current_autonomy_level) - agent_config (config_key, config_value, version_id) - orbita_margins (sku_id, product_name, net_margin, valid_until) - stock_status (sku_id, product_type, quantity, updated_at) - raw_metrics (source, campaign_id, metric_date, metrics_json) - experiments (proposal_id, hypothesis, control_campaign, baseline, result_d7, control_d7, causal_effect, cassiano_verdict, confidence) Adicione RLS em todas as tabelas. Gere como migration SQL pronto para rodar no Supabase.

# Prompt Sessão B — trust_layer.py Construa o trust_layer.py para o agente de tráfego pago da iBob com os 7 checks obrigatórios: 1. Pixel/Tag parado (0 conversões por 6h em horário comercial) 2. Queda brusca de conversões (<30% da média 7 dias) Seta agent_state.dtl_blocked e dtl_state no Supabase. Envia alerta por email quando estado mudar. Escreva também os 7 testes pytest obrigatórios.
